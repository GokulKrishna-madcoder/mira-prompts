Current State Documentation

Executive Summary

This document outlines the current technical SEO, architectural, and content state of the Mira Prompts Next.js platform. It maps out what exists, what is missing, and areas where the current implementation creates bottlenecks for search engine crawlers like Googlebot.

Note: This is a purely descriptive audit for strategic analysis. No fixes have been suggested or applied.

3. Internal Linking & Crawlability

CRITICAL BOTTLENECK: The Logged-Out Homepage

Googlebot navigates the web unauthenticated. Currently, unauthenticated users hit LandingPage.tsx. While this page is visually stunning (waterfall grids, physical interactive cards), it contains ZERO <a href> tags linking to individual prompts. The visuals are purely decorative.

To crawl deeper, bots must rely strictly on the /explore CTA button. The homepage fails to distribute page rank directly to important categories or top prompts.

ORPHAN PAGES
Tag Pages (/tags/[slug])

There are 289 tags in the database with valid dynamic routes. However, the PromptInteractiveViewer.tsx does not display or link out to these tags. Unless they are indexed via the XML sitemap, they are completely orphaned from the site architecture.

STRONG
Explore & Category Pages

The /explore page and /categories/[slug] pages use a Server-Side Rendered MasonryGrid that properly utilizes Next.js <Link> components. Once a bot reaches these pages, it can seamlessly crawl the prompt inventory.

6. Sitelink & Google Understanding

Google awards sitelinks based on a site's hierarchical structure and the flow of PageRank from the homepage to major category hubs.

Current State Analysis:

  • Weak Signal: Because the logged-out homepage acts as an aesthetic landing page without direct HTML links to Categories or Prompts, Google cannot easily infer the site structure from the root domain.
  • Missed Search Intent: Users search heavily for "Midjourney Prompts" or "ChatGPT Prompts". Because tools are just text labels—and not dedicated category pages—Google cannot rank Mira Prompts for these high-volume tool-specific keywords.
  • Category Depth: Categories exist, but they are only one layer deep and rely strictly on the /explore page to pass link equity.
