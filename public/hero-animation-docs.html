📐 2. Shader & Mathematical Physics

Every optical effect — from the liquid fluid distortion to the glass prism rainbow fringing — is governed by an exact mathematical equation evaluated concurrently for each fragment.

1. Aspect-Ratio Corrected Radial Coordinates

In normalized UV space, $(0,0)$ is top-left and $(1,1)$ is bottom-right. On a widescreen monitor (e.g. 16:9), a pure radial distance $\sqrt{x^2 + y^2}$ stretches into an elliptical egg shape rather than a true circle. We correct this by scaling the horizontal delta by the screen aspect ratio:

$$p_x = (uv_x - c_x) \times \frac{\text{resolution}_x}{\text{resolution}_y}, \quad p_y = uv_y - c_y$$ $$\text{dist} = \sqrt{p_x^2 + p_y^2}$$

We then normalize $\text{dist}$ against $maxDist$ (the distance to the furthest screen corner from the click origin $c$):

$$maxDist = \sqrt{\max(c_x, 1 - c_x)^2 \cdot \text{aspect}^2 + \max(c_y, 1 - c_y)^2}$$ $$normDist = \frac{dist}{\max(maxDist, 0.001)}$$

This guarantees the wave spans from $0.0$ to $1.0$ regardless of whether the user clicks dead-center or near the display bezel!

2. Fractal Brownian Motion (FBM) Liquid Warping

A clean circle looks sterile and synthetic. Real liquids feature viscous turbulence. We perturb the radial distance metric using multi-scale Value Noise and Fractal Brownian Motion (FBM):

$$hash21(p) = \text{fract}\Big(\sin(p \cdot 233.34) \times 851.73\Big)$$ $$vnoise(p) = \text{mix}\Big(\text{mix}(a, b, u_x), \; \text{mix}(c, d, u_x), \; u_y\Big), \quad u = f^2(3 - 2f)$$ $$FBM(p, N) = \sum_{k=0}^{N-1} \frac{1}{2^k} \cdot vnoise\left(2^k \cdot p\right)$$

We synthesize two noise fields: a large macro turbulence field (4 octaves) and a high-frequency micro-ripple field (3 octaves), animated by progress over time:

$$warpedDist = normDist + (noiseLarge - 0.5) \cdot 0.3 \cdot \omega + (noiseSmall - 0.5) \cdot 0.1 \cdot \omega$$

3. Traveling Wave Packet: Gaussian Bell × Cosine Ripples

The ripple is modeled as a localized wave packet moving radially outward with coverage factor $1.6$ (ensuring full corner coverage):

$$waveFront = progress \times 1.6, \quad \Delta = warpedDist - waveFront$$ $$baseEnvelope = \exp\left( -\frac{\Delta^2}{2\sigma^2} \right)$$ $$ripples = \max\big(0.0, \; \cos(\Delta \cdot waveFreq)\big)$$ $$envelope = baseEnvelope \times ripples \times \text{smoothstep}(1.0, 0.95, progress)$$

$\sigma = 0.15$ defines the spatial width of the wave packet. The cosine term generates the concentric ripple ridges. Crucially, the terminating gate $\text{smoothstep}(1.0, 0.95, progress)$ zeroes out all wave distortions as progress finishes, guaranteeing the newly revealed image settles in 100% pristine fidelity!

4. Optical Refraction & Chromatic Dispersion (Prism Fringing)

Light passing through water ripples refracts along the wave surface gradient. We displace the texture UV sample coordinates outward along the radial unit vector $\vec{dir} = \frac{\vec{p}}{\|\vec{p}\|}$:

$$\vec{uvOffset} = \vec{dir} \times (envelope \cdot pushAmt)$$

Physical optical dispersion causes red, green, and blue light wavelengths to refract by different amounts ($n_{red} < n_{green} < n_{blue}$). We sample the textures at three distinct color offsets:

$$uv_R = uv - \vec{uvOffset} - \vec{caOffset}$$ $$uv_G = uv - \vec{uvOffset}$$ $$uv_B = uv - \vec{uvOffset} + \vec{caOffset}$$

This produces holographic iridescent edges along the moving wave crest without requiring expensive multi-pass post-processing buffers!

5. Dynamic A/B Ping-Pong Masking

Behind the moving wave crest, the incoming slide is revealed:

$$reveal = 1.0 - \text{smoothstep}(waveFront - feather, waveFront + feather, warpedDist)$$

Instead of allocating 10 GPU textures for 10 slides, we use two texture units (Slot 0 and Slot 1) and toggle the uniform u_swap between 0.0 and 1.0:

$$base = \text{mix}(colorA, colorB, u\_swap), \quad target = \text{mix}(colorB, colorA, u\_swap)$$ $$finalColor = \text{mix}(base, target, reveal)$$

🛡️ 4. WebGL Engine & Reliability Engineering

Critical production defenses preventing browser crashes, memory leaks, and Next.js Hot Module Replacement issues.

The isDestroyed Safety Guard (Fast Refresh Fix)

In Next.js with React Strict Mode and Turbopack Fast Refresh, components are mounted, unmounted, and remounted rapidly. Asynchronous image loading promises (loadImage().then(...)) can resolve after the component cleanup has already invoked destroy() (which deletes the textures and shader program).

Without an atomic flag, calling gl.bindTexture() or gl.useProgram() on deleted WebGL references throws the fatal browser console exception:
WebGL: INVALID_OPERATION: bindTexture: attempt to use a deleted object.
Our isDestroyed guard short-circuits all pending asynchronous uploads and renders, ensuring 100% clean teardown.

Cover-Crop Texture Mapping (object-fit: cover)

Uploading images with arbitrary aspect ratios (e.g. 2400×1600) into a canvas of varying screen dimensions causes severe aspect squishing. The coverCrop() preprocessor renders the source image onto an offscreen 2D canvas scaled with:

$$scale = \max\left(\frac{\text{targetW}}{\text{naturalW}}, \; \frac{\text{targetH}}{\text{naturalH}}\right)$$ $$dw = \text{naturalW} \times scale, \quad dh = \text{naturalH} \times scale$$ $$dx = \frac{\text{targetW} - dw}{2}, \quad dy = \frac{\text{targetH} - dh}{2}$$

This perfectly reproduces CSS object-fit: cover directly inside the GPU texture pixel buffer!

/** Vertex shader — minimal fullscreen quad */
export const VERTEX_SHADER = /* glsl */ `
attribute vec2 a_pos;

void main() {
  // Flip Y so top-left is (0,0) matching browser coordinates
  v_uv = vec2(a_pos.x * 0.5 + 0.5, 0.5 - a_pos.y * 0.5);
  gl_Position = vec4(a_pos, 0.0, 1.0);
}
`

/** Fragment shader — FBM ripple transition with chromatic aberration */
export const FRAGMENT_SHADER = /* glsl */ `
precision mediump float;

varying vec2 v_uv;

uniform sampler2D u_texA;
uniform sampler2D u_texB;

uniform vec2  u_resolution;
uniform vec2  u_center;

uniform float u_progress;
uniform float u_sigma;
uniform float u_waveFreq;
uniform float u_pushAmt;
uniform float u_caStrength;
uniform float u_glow;
uniform float u_noiseWarp;
uniform float u_swap;

// ── Noise: hash → value noise → FBM ──

float hash21(vec2 p) {
  p = fract(p * vec2(233.34, 851.73));
  p += dot(p, p + 23.45);
  return fract(p.x * p.y);
}

float vnoise(vec2 p) {
  vec2 i = floor(p);
  vec2 f = fract(p);
  vec2 u = f * f * (3.0 - 2.0 * f); // smoothstep interpolation

  float a = hash21(i);
  float b = hash21(i + vec2(1.0, 0.0));
  float c = hash21(i + vec2(0.0, 1.0));
  float d = hash21(i + vec2(1.0, 1.0));

  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
}

float fbm(vec2 p, int octaves) {
  float val = 0.0;
  float amp = 0.5;
  for (int i = 0; i < 6; i++) {
    if (i >= octaves) break;
    val += amp * vnoise(p);
    p *= 2.0;
    amp *= 0.5;
  }
  return val;
}

void main() {
  vec2 uv = v_uv;
  vec2 center = u_center;

  // Aspect-ratio–correct radial distance
  float aspect = u_resolution.x / u_resolution.y;
  vec2 p = uv - center;
  p.x *= aspect;

  float dist = length(p);

  // Normalize so the max possible distance ≈ 1
  float maxDist = length(vec2(max(center.x, 1.0 - center.x) * aspect,
                              max(center.y, 1.0 - center.y)));
  float normDist = dist / max(maxDist, 0.001);

  // ── FBM warp ──
  float noiseLarge = fbm(p * 4.0 + vec2(u_progress * 1.0, u_progress * 0.5), 4);
  float noiseSmall = fbm(p * 12.0 + vec2(u_progress * 2.0, -u_progress * 1.5), 3);

  float warpedDist = normDist
    + (noiseLarge - 0.5) * 0.3 * u_noiseWarp
    + (noiseSmall - 0.5) * 0.1 * u_noiseWarp;

  // ── Traveling wave ──
  float coverage = 1.6; // extends past 1.0 so wave reaches all corners
  float waveFront = u_progress * coverage;
  float delta = warpedDist - waveFront;

  float sigma = u_sigma;
  float baseEnvelope = exp(-delta * delta / (2.0 * sigma * sigma));
  float ripples = max(0.0, cos(delta * u_waveFreq));
  float envelope = baseEnvelope * ripples;

  // Gate: kill residual after transition ends
  envelope *= smoothstep(1.0, 0.95, u_progress);

  // ── UV displacement ──
  vec2 dir = (dist > 0.001) ? normalize(p) : vec2(0.0);
  float pushAmt = envelope * u_pushAmt;

  vec2 uvOffset = dir * pushAmt;
  // Un-correct the aspect on x before applying to UV space
  uvOffset.x /= aspect;

  // ── Chromatic aberration ──
  float caStr = envelope * u_caStrength;
  vec2 caDir = (dist > 0.001) ? normalize(p) : vec2(0.0);
  vec2 caOffset = caDir * caStr;
  caOffset.x /= aspect;

  vec2 uvR = uv - uvOffset - caOffset;
  vec2 uvG = uv - uvOffset;
  vec2 uvB = uv - uvOffset + caOffset;

  // ── Sample both textures with CA ──
  vec4 colorA = vec4(
    texture2D(u_texA, uvR).r,
    texture2D(u_texA, uvG).g,
    texture2D(u_texA, uvB).b,
    1.0
  );
  vec4 colorB = vec4(
    texture2D(u_texB, uvR).r,
    texture2D(u_texB, uvG).g,
    texture2D(u_texB, uvB).b,
    1.0
  );

  // ── A/B reveal mask ──
  float feather = 0.08;
  float reveal = smoothstep(waveFront - feather + (noiseLarge - 0.5) * 0.15,
                            waveFront + feather + (noiseLarge - 0.5) * 0.15,
                            warpedDist);
  reveal = 1.0 - reveal; // invert: revealed area = 1

  // Swap logic: u_swap flips which texture is "current" vs "target"
  vec4 base   = mix(colorA, colorB, u_swap);
  vec4 target = mix(colorB, colorA, u_swap);
  vec4 color  = mix(base, target, reveal);

  // ── Glow (optional) ──
  color.rgb += envelope * u_glow * vec3(0.15, 0.1, 0.2);

  gl_FragColor = vec4(color.rgb, 1.0);
}
`

import { VERTEX_SHADER, FRAGMENT_SHADER } from './heroRipple.shader'
import { SHADER_CONFIG, MAX_DPR } from './heroRipple.constants'

export interface RippleState {
  progress: number
  cx: number
  cy: number
  swap: number
}

export interface RippleRenderer {
  uploadTexture: (slot: 0 | 1, image: HTMLImageElement) => void
  render: (state: RippleState) => void
  resize: () => void
  destroy: () => void
  ok: boolean
}

function coverCrop(image: HTMLImageElement, targetW: number, targetH: number): HTMLCanvasElement {
  const c = document.createElement('canvas')
  c.width = targetW
  c.height = targetH
  const ctx = c.getContext('2d')!
  const scale = Math.max(targetW / image.naturalWidth, targetH / image.naturalHeight)
  const dw = image.naturalWidth * scale
  const dh = image.naturalHeight * scale
  ctx.drawImage(image, (targetW - dw) / 2, (targetH - dh) / 2, dw, dh)
  return c
}

export function createRippleRenderer(canvas: HTMLCanvasElement): RippleRenderer {
  const gl = canvas.getContext('webgl', {
    premultipliedAlpha: false,
    alpha: false,
    preserveDrawingBuffer: true,
  })

  if (!gl) return { uploadTexture() {}, render() {}, resize() {}, destroy() {}, ok: false }

  // ... [Shader compilation and buffer setup] ...
  let isDestroyed = false

  function uploadTexture(slot: 0 | 1, image: HTMLImageElement) {
    if (isDestroyed) return
    const unit = slot === 0 ? gl.TEXTURE0 : gl.TEXTURE1
    gl.activeTexture(unit)
    gl.bindTexture(gl.TEXTURE_2D, textures[slot])
    const cropped = coverCrop(image, canvas.width, canvas.height)
    gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, cropped)
  }

  function render(state: RippleState) {
    if (isDestroyed) return
    gl.useProgram(program)
    gl.viewport(0, 0, canvas.width, canvas.height)
    gl.uniform2f(loc.resolution, canvas.width, canvas.height)
    gl.uniform2f(loc.center, state.cx, state.cy)
    gl.uniform1f(loc.progress, state.progress)
    gl.uniform1f(loc.swap, state.swap)
    gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4)
  }

  function destroy() {
    if (isDestroyed) return
    isDestroyed = true
    gl.deleteBuffer(buf)
    gl.deleteTexture(textures[0])
    gl.deleteTexture(textures[1])
    gl.deleteShader(vs)
    gl.deleteShader(fs)
    gl.deleteProgram(program)
  }

  return { uploadTexture, render, resize, destroy, ok: true }
}
